# Автоматические проверки ШТАБ 95

При каждом Pull Request в `main` GitHub Actions запускает:
1. `node --check` для всех `SHTAB-95/js/*.js`.
2. `node --test tests/*.test.mjs` для проверок структуры файлов и важных инвариантов, обнаруженных при первом аудите.

Локальный запуск (Node.js 24+):

```bash
for file in SHTAB-95/js/*.js; do node --check "$file" || exit 1; done
node --test tests/*.test.mjs
```

Тесты в `tests/` пока **статические**: они проверяют наличие ресурсов и защитных условий в исходниках, но не имитируют полноценную игровую сессию и не заменяют браузерное тестирование. Следующий этап — выделить чистые функции из игровой логики и тестировать их результаты.
