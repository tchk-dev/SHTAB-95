# Hydrology comparison and baseline

`river-donja-42.png`: actual browser-rendered 512² terrain raster from the original #42 code (left) and river geometry change (right), same Donja Bukovica seed 42 and entire 40 × 40 km footprint. Temporary test copies exposed the existing terrain canvas at fixed 512 CSS pixels; they did not alter terrain or rendering algorithms. The screenshot crops are presented side by side at the same scale. Crew markers, coordinate labels and weather are omitted because the comparison shows the terrain raster, not the whole game interface. The screenshot is one example, not the required multi-region visual validation. The blue areas are potential filled basins, not calibrated permanent lakes.

`../terrain-validation/cartography-baseline.json`: 13 region/seed combinations × 2 generations from base `9fc3ddf`; 13/13 hashes match `water-mask-fixed-seeds.json`. Node v26.12.1, Intel i7-12700H, 20 logical CPUs; other work including browsers ran concurrently. Full worker-handler VM times: first runs 6.0–17.8 s, median 9.53 s; this is not a browser benchmark and is affected by contention. Generation completed, deterministic fields, flow to edge on filled surface and conservation checks passed. Runtime and source hash are in JSON. Prior browser timing from `TERRAIN-REPORT.md` is a separate measurement.

Lake investigation: priority flood raises depressions to a spill elevation regardless of evaporation, infiltration, groundwater or duration; mask seeds all cells deeper than 0.4 m and then connects shallow shelves. For Mckhetovac/4294967295 the display mask covers 17.6% of the map. This is not evidence of permanent water. Wetland selection uses slope and filled-depth/accumulation thresholds, not an independently calibrated water balance. A defensible permanent-lake classifier needs additional assumptions and validation; neither a cosmetic cutoff nor treating all filled basins as lakes resolves this.
